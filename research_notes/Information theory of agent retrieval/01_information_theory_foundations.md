## 1. Entropy, mutual information, KL divergence and the data processing inequality: can chunking, summarizing or extraction add information about the source?

### Takeaway
No. By the data processing inequality (DPI), any representation computed from a document (parse, chunk, summary, typed record, embedding) carries at most as much Shannon information about any question as the document itself. It carries the same amount for a given question only if it is a sufficient statistic for that question. Only a lossless (invertible) representation is sufficient for every possible future question, which is the formal case for "keep raw evidence as ground truth" and for provenance links. The theorem is about Shannon information under an optimal decoder. Bounded decoders such as LLMs with limited context can extract *more usable* information from processed views (V-information), so derived views are justified as access aids, not as replacements.

### Cited Findings
- **[T1.1] Entropy, uniqueness.** Shannon's Theorem 2: the only function H(p_1..p_n) that is continuous, increasing in n for uniform distributions, and additive under grouping is H = −K Σ p_i log p_i. Theorem 9 (noiseless coding): a source of entropy H per symbol can be sent over a channel of capacity C at an average rate arbitrarily close to C/H symbols per second, and not faster. — [Shannon 1948](https://people.math.harvard.edu/~ctm/home/text/others/shannon/entropy/entropy.pdf). **Maps to:** the information content of a field, ID or token stream is lower-bounded by its entropy. Any lossless encoding of a source record needs at least H bits on average (inference).
- **[T1.2] Kraft–McMillan and optimal code lengths.** Any uniquely decodable binary code with lengths l_a satisfies Σ 2^{−l_a} ≤ 1. Conversely, lengths l_a = ⌈−log P(a)⌉ satisfy Kraft, so a prefix code with expected length < H(X)+1 exists. — [Polyanskiy & Wu, *Information Theory: From Coding to Learning*, Thm 10.9 and §10](https://people.lids.mit.edu/yp/homepage/data/itbook-export.pdf); textbook treatment in [Cover & Thomas, *Elements of Information Theory*, ch. 5](https://doi.org/10.1002/047174882X). **Maps to:** "−log p = code length" is the bridge used by MDL (§3), by "language modeling is compression" (§3) and by surprisal-based chunking and context pruning (§2, §7).
- **[T1.3] KL divergence and mutual information.** D(P‖Q) = Σ P log(P/Q) ≥ 0, with equality iff P = Q (Gibbs). I(X;Y) = D(P_XY ‖ P_X P_Y) = H(Y) − H(Y|X). — introduced as "information for discrimination" in [Kullback & Leibler 1951](https://doi.org/10.1214/aoms/1177729694); properties proved in [Polyanskiy & Wu ch. 2–3](https://people.lids.mit.edu/yp/homepage/data/itbook-export.pdf).
- **[T1.4] Chain rule and DPI.** Polyanskiy & Wu, Thm 3.7 (standard Borel spaces): (a) I(X;Z|Y) ≥ 0, with equality iff X→Y→Z. (b) I(X,Y;Z) = I(X;Z) + I(Y;Z|X) = I(Y;Z) + I(X;Z|Y). (c) **DPI:** if X→Y→Z then I(X;Z) ≤ I(X;Y), with equality iff X→Z→Y. (d) If X→Y→Z→W then I(X;W) ≤ I(Y;Z). **Proof:** expand I(X;Y,Z) both ways with (b). Markovity kills I(X;Z|Y), so I(X;Y) = I(X;Z) + I(X;Y|Z) ≥ I(X;Z). — [Polyanskiy & Wu, Thm 3.7](https://people.lids.mit.edu/yp/homepage/data/itbook-export.pdf); Cover & Thomas Thm 2.8.1 ([book](https://doi.org/10.1002/047174882X)).
  - **Maps to (inference):** model ingestion as the chain Y → S → P → C → Z. Here Y is any question, fact or answer the agent may later need; S is the source bytes; P = parse(S), e.g. a DoclingDocument; C = chunks or records; Z = a summary, wiki page or embedding. Every step after S is a function, possibly randomized (an LLM), of the previous one alone. Then I(Y;Z) ≤ I(Y;C) ≤ I(Y;P) ≤ I(Y;S) for *every* Y. No chunker, extractor or summarizer can add information about the source. The "synthesized wiki page" and "summary tree" layers in SKB and ADL can only lose information relative to the evidence they were built from. Information that appears in Z but not in S is, with respect to S, noise (hallucination) or outside knowledge from the model's parameters, which then needs separate provenance.
- **[T1.5] Sufficient statistics = DPI with equality.** Polyanskiy & Wu, Thm 3.9: T = f(X) is sufficient for θ iff θ→T→X for all P_θ, iff I(θ;X|T) = 0, iff I(θ;X) = I(θ;T). — [Polyanskiy & Wu §3.5](https://people.lids.mit.edu/yp/homepage/data/itbook-export.pdf).
  - **Corollary (my elementary proof, inference):** if T = f(S) is sufficient for *every* question variable Y in a class that contains Y = S itself, then I(S;T) = I(S;S) = H(S). So H(S|T) = 0 and f is injective on the support. *Only a lossless representation is universally sufficient.* A typed record is sufficient for the questions its schema anticipates, and for nothing else guaranteed. **Justifies:** DRC's "extract once into typed records *with source spans*" and SKB's "keep raw evidence as ground truth". The span pointer makes the pair (record, pointer to S) lossless with respect to S whenever the store keeps S. Retaining S plus pointers is the only way to keep re-extraction and re-slicing possible for unanticipated questions, i.e. DRC's "re-sliceable evidence" invariant.
- **[T1.6] Fano's inequality (error floor from lost information).** If |X| = M < ∞ and X→Y→X̂ with P_e = P[X ≠ X̂], then H(X|Y) ≤ P_e log(M−1) + h(P_e). Regardless of |X|, I(X;Y) ≥ (1−P_e) log(1/P_max) − h(P_e), where P_max = max_x P_X(x). Proof: DPI for divergence applied to the indicator 1{X ≠ X̂}. — [Polyanskiy & Wu, Thm 3.12](https://people.lids.mit.edu/yp/homepage/data/itbook-export.pdf).
  - **Maps to (inference):** (i) With DPI: if an extraction Z has H(Y|Z) > H(Y|S), every answerer that sees only Z has an error floor set by H(Y|Z) that no prompt or model can remove. This bounds "answer from records only" designs, and is why DRC requires a routed fallback to raw text for questions outside the schema. (ii) For identifying one of N equiprobable units (P_max = 1/N) with error ≤ P_e, the query representation plus filters must carry at least (1−P_e) log N − h(P_e) bits about the unit ID. For N = 10^7 chunks and P_e = 0.1 that is about 0.9 × 23.25 − 0.47 ≈ 20.5 bits. A metadata pre-filter over 8 equiprobable document types supplies at most 3 of those bits. This quantifies why typed facets, ACL and validity pre-filters and exact identifiers (policy IDs, CVE numbers) help: they are cheap, high-certainty bits.
- **[T1.7] Strong DPI (contraction along chains).** For a channel P_{Z|X}, the contraction coefficient η_KL = sup I(U;Z)/I(U;X) over U→X→Z is ≤ 1, and can be < 1 for noisy channels. Polyanskiy & Wu show how per-channel SDPIs compose into end-to-end bounds for Bayesian networks (Evans–Schulman method), with bounds interpreted as site-percolation probabilities. — [Polyanskiy & Wu 2015, "Strong data-processing inequalities for channels and Bayesian networks"](https://arxiv.org/abs/1508.06025).
  - **Maps to (inference):** for a chain of k stochastic re-summarizations, each with η_i < 1 (an LLM that sometimes drops or garbles facts is such a channel), I(Y; Z_k) ≤ (Π η_i) I(Y; S). Information about the source decays geometrically with depth. This is a formal reason to distrust deep LLM summary trees (RAPTOR-style) and wiki pages synthesized from other summaries, and to build trees from the document's own headings (zero-loss navigation) as SKB recommends. Caveat: η = 1 for deterministic injective maps, so the bound has bite only for genuinely lossy or noisy steps.
- **[T1.8] V-information: computation *can* create usable information.** Xu et al. define predictive V-information for an observer restricted to a function family V. It "encompasses mutual information" and "unlike Shannon's mutual information and in violation of the data processing inequality, V-information can be created through computation". With computational constraints it can be estimated with PAC-style guarantees. — [Xu, Zhao, Song, Stewart & Ermon 2020](https://arxiv.org/abs/2002.10689). **Contradicts a naive reading of [T1.4]:** extraction, summarization and indexing can raise the information a *bounded* agent (finite context, imperfect reasoning) can actually use, even though Shannon information falls. This reconciles the DPI with measured gains from compression: the IB filter in §2 *raises* NQ exact match from 16.2 (no retrieval) and 14.7 (raw top-5) to 21.5 while keeping ~2.5% of the words ([Zhu et al. 2024](https://arxiv.org/abs/2406.01549)).
- **[T1.9] Limits on measuring MI from samples.** Any distribution-free high-confidence lower bound on MI estimated from N samples cannot exceed O(ln N). — [McAllester & Stratos 2018](https://arxiv.org/abs/1811.04251). Existing variational MI lower bounds "degrade when the MI is large, exhibiting either high bias or high variance". — [Poole et al. 2019](https://arxiv.org/abs/1905.06922). **Bounds:** any pipeline metric that claims to "measure how much information a chunk or summary keeps" via neural MI estimates is statistically limited. Task-based proxies (golden-set QA, claim-level recall) are the practical substitute (inference).

### Inferences
- The DPI chain gives the formal ordering behind the earlier reports' layering. Raw source (S) ⊇ parsed tree (P) ⊇ chunks/records (C) ⊇ summaries/wiki/embeddings (Z), in information about anything. Provenance spans are what let a system move back up the chain at query time. Without them, every loss is permanent.
- Two design rules follow. (1) Store S immutably and content-addressed (§6), and treat P, C and Z as *views* that can be recomputed. This matches SKB's "chunking should be a cheap, re-runnable view over a persisted document tree". (2) Judge each derived view by the *usable* information it adds for the deployed agent (V-information, measured as golden-set accuracy). Shannon information is the wrong criterion for a derived view, because it can never exceed the raw store's.
- Deterministic extraction (DRC) does not change the DPI picture. Freezing an LLM's output makes Z a deterministic function of S, which removes run-to-run noise (the η < 1 part from repeated sampling) but not the extraction's loss.

### Gaps
- I found no paper that formally applies the DPI or sufficiency to RAG ingestion pipelines. The chain model above is my framing.
- No empirical estimate of contraction coefficients for LLM summarization channels exists that I could find. The geometric-decay claim is a bound, not a measurement.

## 2. Rate-distortion, lossy compression and the information bottleneck as models for summaries, synthesized pages and context compression

### Takeaway
Rate-distortion theory gives the exact limit of any summary or context compressor: R(D) = min I(S;Ŝ) subject to E d(S,Ŝ) ≤ D. R(D) is convex and non-increasing, so returns diminish. A compressor that knows the query is never worse, and empirically much better, than one that does not. The information bottleneck (IB) is rate-distortion with the distortion induced by a relevance variable Y, and IB-RAG, RECOMP, LLMLingua and Selective Context instantiate it with LLM likelihood proxies, not true MI. Formally, ingest-time summaries are *query-agnostic* compressors, so they can serve only as navigation and recall aids, never as replacements for query-time access to evidence.

### Cited Findings
- **[T2.1] Rate for a fidelity criterion (origin).** Shannon 1948, Theorem 21: if a source has rate R_1 for fidelity valuation v_1 (R_1 = min over P(x,y) with E ρ = v_1 of the MI), it can be encoded and sent over capacity C with fidelity as close to v_1 as desired if R_1 ≤ C, and not if R_1 > C. — [Shannon 1948, Part V](https://people.math.harvard.edu/~ctm/home/text/others/shannon/entropy/entropy.pdf).
- **[T2.2] Rate-distortion theorem (modern form).** For a stationary memoryless source with non-negative separable distortion, D > D_0 and finite D_max: R(D) = R^(I)(D) = inf_{P_{Ŝ|S}: E d(S,Ŝ) ≤ D} I(S;Ŝ) (Thm 25.1). General converse (Thm 24.3): if X→W→X̂ with W ∈ [M] and E d(X,X̂) ≤ D, then log M ≥ inf I(X;Y) over E d ≤ D. Properties (Thm 24.7): R^(I)(D) is convex and non-increasing, and 0 for D > D_max. Gaussian source with MSE (Thm 26.2): R(D) = ½ log⁺(σ²/D). For any source with variance σ² (Thm 26.3): ½ log⁺(σ²/D) − D(P_S‖N(0,σ²)) ≤ R(D) ≤ ½ log⁺(σ²/D), so the Gaussian is the hardest source. — [Polyanskiy & Wu ch. 24–26](https://people.lids.mit.edu/yp/homepage/data/itbook-export.pdf).
  - **Maps to (inference):** convexity means the distortion saved per extra summary token falls as the summary grows. This supports SKB's "one short summary per document, prepended" (cheap first tokens buy the most) over long synthesized pages. The converse is a hard floor. A summary of M possible strings (log M bits) cannot achieve distortion below D(log M) for *any* summarizer, so "summaries that answer everything" are impossible at fixed length.
- **[T2.3] Summarizer rate-distortion function.** Arda & Yener define rate as E[ℓ(S)/ℓ(T)] (summary length over text length, with ℓ(S) ≤ ℓ(T) a.s.) and R_S(D) = min_{p_{S|T}} (1/L̄) I(T;S|ℓ(T)) s.t. E d(T,S) ≤ D. Lemma 1: I(T;S|ℓ(T)) is convex in p_{S|T}. Theorem 1 (converse): any summarizer with E[ℓ(S^n)|ℓ(T^n)] ≤ R ℓ(T^n) and E d ≤ D has R ≥ R_S(D). They compute it with a Blahut–Arimoto-like iteration and compare practical summarizers against it. — [Arda & Yener 2025](https://arxiv.org/abs/2501.13100). **Bounds:** the SKB/ADL "wiki page" and "document summary" layers, if the distortion d is chosen to reflect downstream QA loss (inference).
- **[T2.4] Prompt compression has a computable distortion-rate limit, and query-awareness matters.** Nagle et al. define rate R = E[len(M)/len(X)] and distortion D = E[d(Y, φ_LLM(M,Q))] for a black-box, fixed LLM and hard (token) prompts. D*(R) is the solution of a linear program, Σ_x D_xᵀz_x s.t. Σ R_xᵀz_x ≤ R, 1ᵀz_x = 1, with dual D*(R) = sup_{λ≥0} {−λR + Σ_x min_m [D_{x,m} + λR_{x,m}]}. They distinguish query-agnostic D*(R) (compressor P_{M|X}) from query-aware (P_{M|XQ}). Findings: "a large gap between the performance of current prompt compression methods and the optimal strategy". Query-aware compression is critical, and their variable-rate Adaptive QuerySelect is the only tested method that beats the optimal *query-agnostic* curve. Optimal curves can fall below the no-compression baseline. — [Nagle et al. 2024](https://arxiv.org/abs/2407.15504). The page text I could read did not give numeric gap values.
  - **Maps to (inference):** query-aware compressors contain query-agnostic ones as a special case, so D*_aware(R) ≤ D*_agnostic(R) trivially. The content of the paper is that the gap is large. Ingest-time summaries and wiki pages are query-agnostic by construction. Query-time context filtering (rerank → compress) is query-aware. So keep compression at query time and keep ingestion lossless (§1). Variable rate (different budgets per query or document) is optimal, which supports dynamic context budgets over fixed top-k.
- **[T2.5] Information bottleneck.** Find T (soft clusters or codewords of X) minimizing the Lagrangian I(X;T) − β I(T;Y), i.e. compress X while preserving information about relevance variable Y. It is "a generalization of rate distortion theory in which the distortion measure d(x,x̃) emerges from the joint statistics of X and Y". The solution satisfies self-consistent equations, p(t|x) ∝ p(t) exp(−β D_KL[p(y|x)‖p(y|t)]) with p(y|t) and p(t) as Bayes-consistent marginals. A convergent re-estimation generalizes Blahut–Arimoto. Assumption: p(x,y) is known; Markov chain T←X↔Y (T sees Y only through X). — [Tishby, Pereira & Bialek 1999](https://arxiv.org/abs/physics/0004057). Variational neural version: [Deep VIB, Alemi et al. 2017](https://arxiv.org/abs/1612.00410).
- **[T2.6] IB generalization and caveats.** For a fixed T, with probability ≥ 1−δ over m samples, |I(X;T) − Î(X;T)| ≤ (|T| log m + log|T|)√(log(4/δ))/√(2m) + (|T|−1)/m, with an analogous bound for I(Y;T). The bound does not depend on |X|, and estimating the IB objective is "much easier than estimating p(x,y)". — [Shamir, Sabato & Tishby 2010, Thm 1](https://www.cas.mcmaster.ca/sivansabato/papers/ShamirSabatoTishby10.pdf). If Y is a *deterministic* function of X, (1) the IB curve cannot be recovered by sweeping β in the Lagrangian, (2) trivial solutions exist at every point of the curve, and (3) layers of accurate classifiers cannot show a strict compression–prediction trade-off. — [Kolchinsky, Tracey & Van Kuyk 2019](https://arxiv.org/abs/1808.07593). **Bounds:** IB-based context filters, where the gold answer is close to a deterministic function of (passages, query), sit in exactly this regime. Their β sweeps should be read as heuristics, not as tracing the true IB frontier (inference).
- **[T2.7] IB for RAG noise filtering (stated objective).** min L_IB = I(X̃;X|Q) − β I(X̃;Y|Q). X = retrieved passages, X̃ = extractive compression (a subset of X), Y = gold answer, Q = query. They use the chain rule I(X̃;X|Q) = I(X̃;X|Y,Q) + I(X̃;Y|Q) to get L_IB = I(X̃;X|Y,Q) − (β−1) I(X̃;Y|Q). Estimation: I(X̃;Y|Q) ≈ E log p_LM(y|q,x̃) (dropping H(Y|Q)). Conciseness is bounded via Jensen into a KL form, approximated by the LM likelihood of recovering x from (q,x̃,y). Operational score: IB(x̃) = p_LM(x|[q,x̃,y]) − α p_LM(y|[q,x̃]) (logs applied, α = 10, lower is better). It is used for SFT label selection (with a discard flag when IB(∅) < IB(x̃)), DPO preferences σ(IB(x̃₂) − IB(x̃₁)) and an RL reward −IB. Results (Llama2-7B filter, Llama2-13B reader, DPR top-5): NQ EM 21.5 with 12.7 words vs 14.7 with 517.6 words (top-5) and 16.2 (no retrieval). TriviaQA 52.1 vs 40.7. HotpotQA 26.1 with 13.2 words. — [Zhu et al. 2024](https://arxiv.org/abs/2406.01549). Note (my check): the chain-rule step is exact because X̃ is a function of (X,Q), so I(X̃;Y|X,Q) = 0.
- **[T2.8] RECOMP.** Extractive and abstractive compressors are trained so that the compressed summary, prepended to the reader's input, maximizes end-task performance. The extractive compressor uses a contrastive objective: the positive is the sentence maximizing the LM's log-likelihood of the target. It can output the empty string ("selective augmentation") when documents add no information. Compression to 6% with minimal loss on LM and ODQA. — [Xu, Shi & Choi 2023](https://arxiv.org/abs/2310.04408). **Maps to (inference):** the empty-output option is the IB solution at low β (T independent of X when X carries nothing about Y). It formalizes "abstain from adding context" as a rational outcome.
- **[T2.9] LLMLingua / LongLLMLingua (stated objective).** LongLLMLingua's objective is min_x̃ D_φ(y, ỹ) + λ‖x̃‖₀ over token subsequences x̃ (and document orderings), with D_φ a distance such as KL. Coarse document score r_k = −(1/N_c) Σ log p(x_i^{que,restrict} | x_k^{doc}). Token score: contrastive perplexity s_i = ppl(x_i|x_<i) − ppl(x_i|x^{que},x_<i), which the authors relate to conditional pointwise MI. Dynamic per-document compression ratio by rank. Reported: up to +21.4% on NaturalQuestions with ~4× fewer tokens on GPT-3.5-Turbo, and 94.0% cost reduction on LooGLE. — [Jiang et al. 2023b](https://arxiv.org/abs/2310.06839). LLMLingua (budget controller, iterative token-level compression, up to 20×). — [Jiang et al. 2023a](https://arxiv.org/abs/2310.05736).
- **[T2.10] Selective Context (self-information pruning).** Prunes lexical units with low self-information I(x_t) = −log₂ P(x_t|x_<t), aggregated over phrases or sentences. 50% context reduction gave −36% memory and −32% inference time, with −0.023 BERTScore and −0.038 faithfulness. — [Li et al. 2023](https://arxiv.org/abs/2310.06201). **Bounds (inference):** this is query-agnostic compression in Nagle's taxonomy [T2.4], so it is dominated by query-aware methods at equal rate.
- **[T2.11] IB and KL views of summarization.** BottleSum maps IB to "a compressed sentence that can best predict the next sentence" (Y = next sentence) for unsupervised extractive summarization. — [West et al. 2019](https://arxiv.org/abs/1909.07405). Peyrard defines Redundancy Red(S) = H_max − H(S), Relevance Rel(S,D) = −CE(S,D), Informativeness Inf(S,K) = CE(S,K) relative to background knowledge K. Importance θ_I(S,D,K) = −KL(P_S ‖ P_{D/K}), and −KL(S‖D) = Rel(S,D) − Red(S). — [Peyrard 2019](https://aclanthology.org/P19-1101/). **Maps to (inference):** Peyrard's Informativeness formalizes "write a page only for what is *not* already in the reader's background K". For glossary layers, K is the model's prior, so a glossary should carry domain-specific senses (low P_K) rather than generic definitions.

### Inferences
- **What summaries are for.** Under [T2.2]–[T2.4], an ingest-time summary of fixed length is a query-agnostic code with a strictly positive distortion floor for some queries. It should be used where its distortion is irrelevant (routing, navigation, document-identity prefix for retrieval, as in SKB's measured prefix gains) and never as the reader's sole evidence. This matches, and gives a formal basis for, SKB's findings that summary trees work as navigation rather than through their generated content.
- **Where compression belongs.** Query-aware, variable-rate compression at read time (rerank → filter → compress, with the option of an empty context) is the theoretically preferred place to lose information, because it can use Q.
- **Proxies.** None of the RAG IB methods computes mutual information. All replace it with LM log-likelihoods, so their guarantees are heuristic and model-specific. Their *objectives* are still useful as evaluation scores, e.g. the IB score as a golden-set metric for a compression stage.

### Gaps
- No public study computes a summarizer R(D) curve on real enterprise documents with a QA-based distortion. Arda & Yener's experiments use small data, and Nagle et al. use synthetic Markov prompts plus a small NL set.
- I could not extract numeric gaps to optimum from Nagle et al.'s figures in the text I could access.

## 3. Minimum description length and Kolmogorov complexity for schema and structure discovery, taxonomy induction, pattern and rule mining, and "language modeling is compression"

### Takeaway
MDL turns "find the structure" into "find the shortest two-part code": L(H) + L(D|H). It gives a parameter-light, principled criterion for choosing patterns (Krimp), taxonomy cut levels (Li & Abe), KG rules and schemas (KGist), graph summaries (VoG) and segment boundaries (Utiyama–Isahara). Kolmogorov complexity is the ideal but incomputable limit. Practical stand-ins are real compressors (NCD) and LLM log-loss, which is literally a code length. Model cost has to be counted: two-part accounting penalizes huge models on small corpora.

### Cited Findings
- **[T3.1] Two-part (crude) MDL.** Choose the hypothesis H minimizing L(H) + L(D|H), with L(D|H) = −log P(D|H) the code length of the data under H. Refined MDL replaces this with universal codes (normalized maximum likelihood, minimax regret over data). — [Grünwald 2004 tutorial](https://arxiv.org/abs/math/0406077); origin [Rissanen 1978, "Modeling by shortest data description"](https://doi.org/10.1016/0005-1098%2878%2990005-5) (metadata verified; content via Grünwald's tutorial).
- **[T3.2] Kolmogorov complexity: invariance, incompressibility, incomputability.** K_U(x) is the length of the shortest program on a universal machine U that outputs x. Invariance: |K_U(x) − K_V(x)| ≤ c_{UV} for universal U, V. Incompressibility (counting proof): there are 2^n strings of length n but only 2^n − 1 programs shorter than n, so some string has K(x) ≥ n. More generally, fewer than 2^{n−c} strings have K(x) < n − c. K is not computable. — [Kolmogorov 1965/1968](https://doi.org/10.1080/00207166808803030); textbook [Li & Vitányi 2019](https://doi.org/10.1007/978-3-030-11298-1) (metadata verified; the counting proof is reproduced here). Universal information distance max{K(x|y), K(y|x)} is a metric, minimal up to additive log terms among "admissible" distances. — [Bennett, Gács, Li, Vitányi & Zurek 1998](https://arxiv.org/abs/1006.3520).
- **[T3.3] Structure function (model vs noise).** Kolmogorov's structure function, for data x and model sets S ∋ x of complexity ≤ α, gives the least log|S|. It "determines all stochastic properties of the data", and the "algorithmic minimal sufficient statistic" separates meaningful structure from random residue. — [Vereshchagin & Vitányi 2004](https://arxiv.org/abs/cs/0204037). **Maps to (inference):** a typed schema plus a record is a two-part code, i.e. a model set S (all instances the schema admits) and an index of x within S. A good schema is one where K(S) + log|S| ≈ K(x): schema captures the regular part, fields carry the irreducible part. This is the formal analogue of DRC's "schema/field specification explains most variance".
- **[T3.4] Normalized compression distance.** NCD(x,y) = (C(xy) − min{C(x),C(y)}) / max{C(x),C(y)} approximates the (incomputable) normalized information distance with a real compressor C. For "normal" compressors it is a similarity metric that "approximates universality", and it clusters across domains. — [Cilibrasi & Vitányi 2005](https://arxiv.org/abs/cs/0312044). **Maps to (inference):** a model-free near-duplicate and version-chain signal (e.g. zstd-NCD between candidate document versions) to complement MinHash (§6). It is cheap for pairwise checks after LSH blocking but quadratic if used alone.
- **[T3.5] Krimp: patterns that compress.** A code table CT of itemsets is chosen to minimize L(D, CT) = L(D|CT) + L(CT|D), with code lengths L(code_CT(X)) = −log P(X|D) from usage frequencies (Defs 3–5). This "typically" returns hundreds of itemsets, "up to seven orders of magnitude" fewer than frequent itemsets, and the code tables are good classifiers. — [Vreeken, van Leeuwen & Siebes 2011](https://doi.org/10.1007/s10618-010-0202-x) ([open PDF copy](https://perso.liris.cnrs.fr/marc.plantevit/ENS/papers2014/MDL.pdf)). Rule lists for classification by MDL (Classy). — [Proença & van Leeuwen 2020](https://arxiv.org/abs/1905.00328). **Maps to (inference):** mining recurring field or value patterns in extracted records, rule cards or SOP step sequences without a support threshold. Candidate "rule card" templates or alias-table entries are those that shorten the corpus's description.
- **[T3.6] MDL taxonomy cuts.** Li & Abe estimate a distribution over a partition of words restricted to *cuts* of a thesaurus tree. They choose the cut ("tree cut model") minimizing description length, with an efficient algorithm that "provably obtains the optimal tree cut model … in the sense of MDL". — [Li & Abe 1995/1998](https://arxiv.org/abs/cmp-lg/9507011). **Maps to (inference):** choosing the granularity of a taxonomy or glossary layer (which level of a category tree to expose as facets) by MDL over observed query or document assignments, rather than by hand.
- **[T3.7] MDL summaries of graphs and KGs.** KGist learns labeled, rooted-graph rules that "best compress the KG according to the MDL principle". Rules describe what is normal; poorly compressed parts are errors, and rule exceptions locate missing information ("up to 93% of missing entities" located). Evaluated on NELL, DBpedia and Yago. — [Belth et al. 2020](https://arxiv.org/abs/2003.10412). VoG: include a subgraph (star, clique, chain…) in a summary iff it decreases the total description length. — [Koutra et al. 2014](https://arxiv.org/abs/1406.3411). **Maps to (inference):** ADL calls schema induction "research-grade". MDL gives an objective for it, and for type-conditional completeness checks ("entities of type Policy normally have an owner and an effective date") that act as data-quality gates.
- **[T3.8] Language modeling is compression.** With arithmetic coding, a predictive model's log-loss is its compressed length (overhead about 2 bits), so "minimizing the log-loss is equivalent to minimizing the compression rate". Chinchilla 70B compresses enwik9 to 8.3% raw (gzip 32.3%) but 14008.3% *adjusted* when its ~140 GB of parameters are counted (two-part code). Context length limits offline compression. "Tokenization is already a form of lossless compression". — [Delétang et al. 2024](https://arxiv.org/abs/2309.10668). Across 31 LLMs, average benchmark score correlates almost linearly with compression efficiency on external corpora. — [Huang et al. 2024](https://arxiv.org/abs/2404.09937) (correlational).
  - **Maps to (inference):** (i) per-token surprisal −log p(x_t|x_<t) under any fixed LM is a usable, deterministic-given-weights estimate of the conditional information in each span. This underlies Selective Context [T2.10], surprisal segmentation (§7) and "novelty" scoring for dedup. (ii) The two-part accounting is a warning: an LLM-based "compressed wiki" of a small corpus is not a compression of it once the model is counted. Its value is usability (V-information), not information (§1).

### Inferences
- MDL is the information-theoretic answer to SKB's "glossary/taxonomy layers" and ADL's "schema induction" questions. Keep a structure (type, field, rule, taxonomy level) iff it shortens the total description of the corpus. Every proposed layer then has a measurable, model-free score that complements golden-set gains.
- Because K is incomputable, every practical MDL method depends on its chosen code (Krimp's code tables, KGist's rule encoding). Results are relative to that encoding. That is acceptable for ranking candidate schemas, not for claiming "the true schema".

### Gaps
- I found no study applying MDL schema selection to LLM-extracted document records (as opposed to transactional data or KGs).
- Huang et al.'s compression–capability link is correlational across model families. It does not show that compression causes retrieval quality.

## 4. Information-theoretic database design: Arenas & Libkin normal forms, entropy-based dependency discovery, redundancy and data-quality measures

### Takeaway
Redundancy has an exact information-theoretic definition. A schema is in BCNF (FDs) or 4NF (FDs+MVDs) iff every position in every instance carries maximal information, and normalization never decreases per-position information. Dependency-preserving designs must pay a redundancy price of at least 1/2, and 3NF achieves exactly 1/2. FDs and MVDs are entropy and conditional-MI constraints (H(Y|X) = 0, I(Y;Z|X) = 0), which makes approximate dependency discovery and data-quality scoring information-theoretic too. For the toolkit: keep the canonical typed store normalized, and put deliberate redundancy (breadcrumbs, denormalized chunk metadata) only in derived retrieval views.

### Cited Findings
- **[T4.1] Entropy characterization of BCNF/4NF (simple measure).** For instance I, position p and domain [1,k], define a distribution E_k(I,p) uniform over values a such that I_{p←a} still satisfies Σ. Thm 3.1: (S,Σ) with FDs (resp. FDs+MVDs) is in BCNF (resp. 4NF) iff for every k > 1, I ∈ inst_k(S,Σ) and p, H(E_k(I,p)) > 0. Proof (⇒): if X is a key, replacing p by the fresh value k+1 cannot violate an FD. (⇐): a non-key X → A gives a two-tuple instance where t₁[A] is forced, so entropy is 0. — [Arenas & Libkin 2005 (JACM)](https://doi.org/10.1145/1059513.1059519) ([PDF](https://marceloarenas.cl/publications/jacm05.pdf)).
- **[T4.2] Well-designed = maximal relative information (refined measure).** INF_I(p|Σ) = lim_{k→∞} INF^k_I(p|Σ)/log k ∈ [0,1], defined via conditional entropy averaged over which other positions are also lost (Def 4.5, limit exists by Lemma 4.4). A specification is *well designed* iff INF_I(p|Σ) = 1 for all I, p (Def 4.6). Thm 4.22: with only FDs and MVDs, well designed ⇔ 4NF. With only FDs, ⇔ BCNF. Thm 4.17 extends this to FDs+JDs (justifying PJ/NF, 5NFR). Thm 6.1: one BCNF-decomposition step (X→Y, split into XY and XZ) never decreases information: INF_I(p|Σ) ≤ INF_{I_U}(π_U(p)|Σ_U). The same measure characterizes the XML normal form XNF. — [Arenas & Libkin 2005](https://marceloarenas.cl/publications/jacm05.pdf).
- **[T4.3] Price of dependency preservation.** Using the same [0,1] measure, every dependency-preserving normal form has a worst-case redundancy "price" of at least 1/2, 3NF achieves exactly 1/2, and only prime attributes can carry redundancy in 3NF. — [Kolahi & Libkin, PODS 2006](https://doi.org/10.1145/1142351.1142369); journal version [Kolahi & Libkin, TODS 2010](https://doi.org/10.1145/1670243.1670248) (abstract-level verification via aggregators; full text not read).
- **[T4.4] Dependencies as information measures.** Under the empirical (uniform-over-tuples) distribution of relation R, X → Y holds iff H(Y|X) = 0, and the MVD X ↠ Y | Z holds iff I(Y;Z|X) = 0. These are special cases of conditional independence. — reviewed in [Kenig & Suciu 2022](https://arxiv.org/abs/1812.09987) (citing Lee 1987 and Dalkilic & Robertson 2000). Dalkilic & Robertson's "information dependencies" quantify the residual uncertainty of Y given X and derive Armstrong's axioms from entropy inequalities. — [Dalkilic & Robertson, PODS 2000](https://doi.org/10.1145/335168.336059) (abstract-level).
- **[T4.5] Approximate implication (error propagation for constraints).** Kenig & Suciu define the degree of satisfaction of constraints by H(·|·) or I(·;·|·) and ask when exact implication Σ ⇒ τ relaxes to h(τ) ≤ λ·h(Σ). Any implication among MVDs+FDs relaxes with a factor at most quadratic in the number of variables, and with factor 1 when the consequent is an FD. Some CI implications admit no relaxation but all relax "in the limit". Repair bound: if h(Y|X) = c on relation R (key X→Y, XY = Ω), then |R|/|Π_X R| ≤ 2^c, so at most (2^c − 1)|Π_X R| tuples need repair. — [Kenig & Suciu 2022](https://arxiv.org/abs/1812.09987). **Maps to (inference):** a *quantitative* data-quality gate for LLM-extracted tables. Measure h(Y|X) for declared keys and FDs per snapshot. A non-zero value bounds the number of conflicting records, and by relaxation it bounds violations of implied FDs. This turns DRC's "deterministic checks first" into graded checks with propagation guarantees.
- **[T4.6] Reliable entropy-based FD discovery.** The fraction of information F(X;Y) = (H(Y) − H(Y|X))/H(Y) equals 1 for an FD and 0 for independence. The plug-in estimator is biased upward and favors large X ("a functional dependence is indicated when X and Y are actually independent" at high dimensionality). Mandros et al. give a bias-corrected "reliable" F with an optimistic estimator for branch-and-bound top-k discovery with optimality guarantees. — [Mandros, Boley & Vreeken 2017](https://arxiv.org/abs/1705.09391). Maimon mines approximate MVDs and acyclic schemas with an information-theoretic notion of approximation, scaling to 1M rows and 30 columns on 20 datasets. — [Kenig et al. 2020](https://arxiv.org/abs/1911.12933).
  - **Maps to (inference):** DRC's "let profiling and lookups decide structure". After extraction, profile candidate keys and FDs with reliable F, propose a decomposition (BCNF/4NF via [T4.2]), and keep the canonical record store in that form. Plug-in entropy on small extraction batches will hallucinate dependencies, so use the corrected estimator or a held-out check.

### Inferences
- **Canonical store vs retrieval views.** [T4.2] says normalized schemas waste no position. [T4.3] says preserving all dependencies locally costs redundancy ≥ 1/2. SKB's heading-path prefix and repeated document metadata on each chunk are *intentional redundancy* (zero information per repeated position under the document FD chunk → doc_title). They are justified for retrieval (§1, Fano bits) but belong in a materialized, regenerable view, not in the canonical facts table, where they would create update anomalies (stale titles or effective dates on some chunks).
- **Typed knowledge units.** A unit envelope with ID, version, validity window and owner, plus type-specific tables (rule cards, step graphs), is a 4NF-style decomposition. Multi-valued facts (a rule's many applicability tags) go in separate relations rather than repeated columns.

### Gaps
- No work I found applies the Arenas–Libkin measure to JSON or document-store schemas produced by LLM extraction. The XML (XNF) result is the nearest analogue.
- The Kolahi–Libkin full text was not accessible. The 1/2 result is taken from the abstract as reported by aggregators.

## 5. Embedding capacity and geometry: Johnson–Lindenstrauss, sign-rank and top-k expressivity limits, dense vs sparse capacity, quantization distortion

### Takeaway
JL says n points can be embedded in O(ε⁻² log n) dimensions with all pairwise distances preserved within 1±ε, and this is optimal in the worst case. For realistic n and ε the guaranteed dimension is far above 768–4096. Retrieval needs only ranking preservation, governed by the *margin*. Long documents have small normalized margins, so fixed-length vectors lose precision as documents grow. The number of distinct top-k sets a d-dimensional single-vector index can return is bounded (LIMIT, via sign-rank). Quantization error bounds distance error and has a Gaussian worst case. Together these are a formal basis for SKB's "keep a lexical channel", hybrid retrieval and full-precision reranking.

### Cited Findings
- **[T5.1] JL lemma (upper bound) and proof idea.** For 0 < ε < 1 and k ≥ 4(ε²/2 − ε³/3)⁻¹ ln n, any n points in R^d map to R^k with (1−ε)‖u−v‖² ≤ ‖f(u)−f(v)‖² ≤ (1+ε)‖u−v‖² for all pairs. — [Dasgupta & Gupta 2003](https://doi.org/10.1002/rsa.10073) (statement cross-checked against the proof condition in [Wikipedia's JL article](https://en.wikipedia.org/wiki/Johnson%E2%80%93Lindenstrauss_lemma)). Proof idea: for a Gaussian matrix R, ‖Rx/√k‖² / ‖x‖² is χ²_k / k. Its tails give Pr[|‖Rx/√k‖ − ‖x‖| > ε‖x‖] ≤ 1/n² for k = O(log n/ε²), and a union bound over C(n,2) difference vectors gives success with probability ≥ 1/2. — [Liberty lecture notes](https://edoliberty.com/classnotes/datamining2012/pdfs/05_random_projections.pdf). ±1 or sparse "database-friendly" matrices also work. — [Achlioptas 2003](https://doi.org/10.1016/S0022-0000%2803%2900025-4) (via the Wikipedia summary).
  - Worked numbers (mine): n = 10⁷ chunks, ε = 0.1 needs k ≥ 4·16.12/0.004667 ≈ 13,800. n = 10⁶, ε = 0.2 needs ≈ 3,200.
- **[T5.2] JL is optimal.** For 1/min{n,d}^{0.4999} < ε < 1 there exist n points such that *any* map (linear or not) with (1±ε) distortion needs m = Ω(ε⁻² lg n). — [Larsen & Nelson 2017](https://arxiv.org/abs/1609.02094). **Bounds:** no embedding can preserve *all* pairwise geometry of a large corpus at low dimension. Learned embedders succeed only by preserving the geometry that matters for the query distribution, and fail where queries probe geometry they discarded (inference).
- **[T5.3] Margin-based dimension bounds for retrieval.** Normalized margin μ(q,d₁,d₂) = ⟨q, d₁−d₂⟩ / (‖q‖‖d₁−d₂‖). Lemma 1: for a Gaussian or Rademacher A ∈ R^{k×d}, the pairwise ranking-error probability β ≤ 4 exp(−(k/2)(ε²/2 − ε³/3)) with ε = μ, so k ≥ 2(ε²/2 − ε³/3)⁻¹ ln(4/β) suffices. Lemma 2 (recall-at-r₀ = 1 w.p. ≥ 1−β): k ≥ 2/(ε²/2 − ε³/3) · ln(4(|D| − r₀ + 1)/β), with ε the r₀-th smallest margin. Corollary 2 (boolean bag-of-words): k ≥ 24 L_Q L_D ln(4/β), with L_Q and L_D the max unique terms of query and documents. The bound is empirically tight up to a constant, and margins shrink with document length, "suggesting limitations in the capacity of fixed-length encodings to support precise retrieval of long documents". Sparse–dense hybrids and multi-vector models are proposed. — [Luan, Eisenstein, Toutanova & Collins 2021 (TACL)](https://arxiv.org/abs/2005.00181).
  - Worked number (mine): L_Q = 5, L_D = 500, β = 0.05 gives k ≥ 24·5·500·ln 80 ≈ 2.6×10⁵. Random projection of a long-document BoW cannot guarantee exact term-match ranking at practical k, whereas a sparse inverted index represents it exactly. **Justifies:** SKB's "match small, read large" (short units have larger margins) and the mandatory lexical channel.
- **[T5.4] Dense retrieval degrades faster with index size.** "Theoretically and empirically … the performance for dense representations decreases quicker than sparse representations for increasing index sizes", up to a tipping point where sparse wins. The effect is "tightly connected to the number of dimensions": lower d means more false positives. — [Reimers & Gurevych 2021](https://arxiv.org/abs/2012.14210).
- **[T5.5] LIMIT: top-k expressivity bounded by dimension.** Thm 1 (margin realizability): if every k-subset of n unit document vectors is realizable as a top-k by some unit query with margin γ, then C(n,k) ≤ (1+1/γ)^d, i.e. d ≥ log C(n,k)/log(1+1/γ). Proof: queries for distinct subsets are ≥ 2γ apart, so disjoint γ-balls pack into a radius-(1+γ) ball. Prop 2 (binary qrel matrix A): rank_±(2A−1) − 1 ≤ rank_rop(A) = rank_rt(A) ≤ rank_gt(A) ≤ rank_±(2A−1), so the minimum dimension that realizes A's row-wise top sets is within 1 of its sign-rank. Free-embedding experiments (vectors optimized directly on the test set) give a critical n fitted by a cubic in d (r² = 0.999), extrapolating to ~500k documents at d = 512, 4M at 1024 and 250M at 4096 for *all* top-2 combinations (measured only up to d = 45, n = 626). On LIMIT (50k docs, 1,000 queries, k = 2), BM25 reaches R@100 = 93.6 and GTE-ModernColBERT (multi-vector) 54.8, while the best single-vector model reaches 18.9. — [Weller, Boratko, Naim & Lee 2025](https://arxiv.org/abs/2508.21038). Sign-rank tools: [Alon, Frankl & Rödl 1985](https://doi.org/10.1109/SFCS.1985.30); a √n lower bound on the sign-rank of n×n Hadamard matrices: [Forster 2002](https://doi.org/10.1016/S0022-0000%2802%2900019-3) (metadata verified; result as cited in the LIMIT appendix and standard literature).
  - **Caveat (my calculation):** Thm 1 alone is weak. For n = 10⁶, k = 2, γ = 0.1 it gives only d ≥ ln(5×10¹¹)/ln 11 ≈ 11. The practical bite comes from the sign-rank characterization and the free-embedding experiments, and both concern *all* top-k combinations. Real query logs probe a small subset, so LIMIT bounds expressivity (worst case), not typical accuracy. **Inference:** combinatorial queries (conjunctions of attributes, "who likes X and Y") are where single-vector retrieval provably needs either more dimensions, multi-vector or sparse representations, or structured filters, which supports DRC's "typed records + exact query" for attribute-conjunction questions.
- **[T5.6] Contrastive training and MI.** InfoNCE with N candidates gives I(x; c) ≥ log N − L_N. — [van den Oord, Li & Vinyals 2018 (CPC)](https://arxiv.org/abs/1807.03748). Variational MI lower bounds have high bias or variance at large MI. — [Poole et al. 2019](https://arxiv.org/abs/1905.06922). **Bounds (inference):** the InfoNCE objective can certify at most log N nats per batch, so it does not measure whether an embedder captures all query-relevant information. It is consistent with McAllester & Stratos [T1.9].
- **[T5.7] Quantization distortion.** For product quantization (subvectors quantized separately), MSE(q) = Σ_j MSE(q_j). For asymmetric distance computation (ADC), the mean squared distance error is bounded by the quantizer's MSE: MSDE(q) ≤ MSE(q). For symmetric computation (SDC) it is ≤ 2·MSE. — [Jégou, Douze & Schmid 2011](https://inria.hal.science/inria-00514462). RaBitQ quantizes D-dim vectors to D-bit strings with "a sharp theoretical error bound", noting that PQ "do[es] not have a theoretical error bound" on distance estimates and can "fail disastrously on some real-world datasets". — [Gao & Long 2024](https://arxiv.org/abs/2405.12497). Rate-distortion floor: for i.i.d. N(0,σ²) coordinates, D(R) = σ²2^{−2R} per dimension, and any source of variance σ² is no harder (R(D) ≤ ½ log(σ²/D)). — [Polyanskiy & Wu Thms 26.2–26.3](https://people.lids.mit.edu/yp/homepage/data/itbook-export.pdf).
  - **Maps to (inference):** at 64-bit PQ codes for d = 128 (0.5 bit/dim), an isotropic Gaussian source would have relative MSE ≥ 2^{−1} = 50% per dimension. Real embeddings do much better only because their spectrum is skewed (reverse water-filling). Keep full-precision vectors, the vector-space analogue of raw evidence, for a rerank stage. Use the quantizer's measured MSE as the error budget, as Jégou suggests.

### Inferences
- The theorems give three *independent* reasons for hybrid retrieval: worst-case geometry needs O(ε⁻² log n) dimensions [T5.1–T5.2]; long documents have small margins [T5.3–T5.4]; combinatorial top-k sets need sign-rank-many dimensions [T5.5]. Sparse lexical indexes avoid all three, because their dimension is the vocabulary and their scores are exact for term matches.
- Chunk-size choice has a geometric component. Smaller units mean larger normalized margins (fewer competing terms per vector) but more vectors (larger n, more log n). This trade-off is consistent with SKB's 256–512-token structural units, but no theorem fixes the optimum (inference).

### Gaps
- No closed-form result links embedding dimension to recall for *learned* (non-random) embedders on natural query distributions. LIMIT's free-embedding curve is an empirical extrapolation beyond d = 45.
- I did not find a rate-distortion analysis of PQ on real text-embedding spectra.

## 6. Hashing and deduplication: MinHash, SimHash, Bloom filters, content addressing, Merkle trees and the birthday bound

### Takeaway
MinHash gives an unbiased Jaccard estimator whose variance falls as 1/k. Banding turns it into a tunable threshold detector. SimHash estimates angle via Pr[bit agrees] = 1 − θ/π. Bloom filters have a known false-positive formula, are within log₂e ≈ 1.44 of the space lower bound, and a false positive in a dedup filter silently drops a new document. Content addressing is safe exactly as far as the birthday bound and the hash's collision resistance allow: SHA-256 is effectively collision-free at data-lake scale, 64-bit IDs are not, and SHA-1 is broken. These results make DRC's determinism invariants (identical rebuilds, snapshot identity) and SKB's dedup pipeline quantitatively specifiable.

### Cited Findings
- **[T6.1] MinHash unbiasedness (Broder).** Let S(A,w) be A's w-shingles, π a uniformly random permutation of the shingle universe, r_w(A,B) = |S_A ∩ S_B| / |S_A ∪ S_B|. Theorem 1: |MIN_s(M(A) ∪ M(B)) ∩ M(A) ∩ M(B)| / |MIN_s(M(A) ∪ M(B))| is an unbiased estimate of resemblance, where M(·) = MIN_s(π(S(·))). |L(A) ∩ L(B)| / |L(A) ∪ L(B)| (mod-m sampling) estimates resemblance, and |L(A) ∩ L(B)| / |L(A)| estimates containment. Key step: if α is the smallest element of π(S_A ∪ S_B), then Pr[α ∈ M(A) ∩ M(B)] = Pr[π⁻¹(α) ∈ S_A ∩ S_B] = r_w(A,B), because π⁻¹(α) is uniform over the union. With ℓ-bit shingle IDs, the estimated quantity becomes r_{w,f}, so ID collisions bias the estimate. — [Broder 1997](https://doi.org/10.1109/SEQUEN.1997.666900) ([PDF](https://www.cs.princeton.edu/courses/archive/spring13/cos598C/broder97resemblance.pdf)). Hash families that are only approximately min-wise independent suffice up to stated error. — [Broder, Charikar, Frieze & Mitzenmacher 2000](https://doi.org/10.1006/jcss.1999.1690) (metadata verified).
  - **Derived (my derivations, inference):** with k independent permutations, the estimate Ĵ = (1/k) Σ 1[min π_i(A) = min π_i(B)] is Binomial(k,J)/k, so Var = J(1−J)/k. For J = 0.8, k = 128, SD ≈ 0.035. LSH banding with b bands of r rows declares a candidate with probability 1 − (1 − J^r)^b, threshold ≈ (1/b)^{1/r}. For b = 16, r = 8: P(J=0.8) ≈ 0.95, P(J=0.5) ≈ 0.06, threshold ≈ 0.71. This makes SKB's "MinHash-LSH for near-duplicates" a tunable precision/recall operating point that can be stated in a config.
- **[T6.2] SimHash / random hyperplanes (Charikar).** For h_r(u) = 1[r·u ≥ 0] with r Gaussian, Pr[h_r(u) = h_r(v)] = 1 − θ(u,v)/π. This is the Goemans–Williamson rounding lemma. For sets as characteristic vectors, θ = cos⁻¹(|A∩B| / √(|A||B|)). Any LSH family for sim can be turned into a 1-bit family for (1+sim)/2. — [Charikar 2002](https://doi.org/10.1145/509907.509965) ([PDF](https://www.cs.princeton.edu/courses/archive/spr04/cos598B/bib/CharikarEstim.pdf)); [Goemans & Williamson 1995](https://doi.org/10.1145/227683.227684) (metadata verified). At web scale (8B pages), 64-bit SimHash with Hamming threshold k = 3 gave precision and recall both "near 0.75". — [Manku, Jain & Das Sarma 2007](https://doi.org/10.1145/1242572.1242592) ([PDF](https://static.googleusercontent.com/media/research.google.com/en//pubs/archive/33026.pdf)).
  - **Derived (inference):** with f independent hyperplanes the Hamming distance is Binomial(f, θ/π). An expected distance ≤ 3 of 64 corresponds to θ ≤ 3π/64 ≈ 8.4° (cosine ≈ 0.989), i.e. a very tight near-duplicate notion. Manku's simhash uses hashed weighted features rather than Gaussian hyperplanes, so the Binomial model is only approximate, consistent with the modest measured precision and recall. Thresholds must be tuned on local labeled pairs, as SKB says.
- **[T6.3] Bloom filters.** n elements, m bits, k hash functions: the false-positive rate is approximately f = (1 − e^{−kn/m})^k, minimized at k = (m/n) ln 2, giving f ≈ (0.6185)^{m/n}. Lower bound: any structure with false-positive rate ε needs m ≥ n log₂(1/ε) bits, so Bloom filters are within log₂ e ≈ 1.44 of optimal. — [Broder & Mitzenmacher 2004](https://www.eecs.harvard.edu/~michaelm/postscripts/im2005b.pdf); original [Bloom 1970](https://doi.org/10.1145/362686.362692) (metadata verified). The classical p_k = (1 − (1 − 1/m)^{kn})^k is actually a *strict lower bound* on the true false-positive rate. Bose et al. give correct upper and lower bounds that converge to p_k for common parameters. — [Bose et al. 2008](https://cglab.ca/~morin/publications/ds/bloom-submitted.pdf).
  - **Maps to (inference):** at 10 bits/element and k = 7, f ≈ 0.82% (the lower bound at that space would be 2^{−10} ≈ 0.098%). In an ingest "already seen?" filter, a false positive means a *new* document is skipped as a duplicate, which is silent data loss and breaks DRC's zero-call-rebuild and completeness invariants. Use Bloom filters only as a negative pre-filter (a "no" is certain), followed by exact hash lookup on "maybe".
- **[T6.4] Birthday bound (collision probability of content IDs).** For k i.i.d. uniform values in a set of size N, Pr[collision] ≥ 1 − e^{−k(k−1)/2N} ≥ min{k(k−1)/(4N), 0.63}. Non-uniform i.i.d. values only raise it (Blom). The union bound gives Pr ≤ k(k−1)/(2N). For collision probability ≤ δ after s evaluations, the digest space needs |T| ≥ s²/δ (e.g. 2⁸⁰ evaluations at δ = 2⁻⁸⁰ needs ≥ 240-bit digests). — [Boneh & Shoup, *A Graduate Course in Applied Cryptography*, Thm B.1, Cor. B.2, §8.3](https://toc.cryptobook.us/).
  - Worked numbers (mine): 64-bit IDs at k = 10⁹ objects give Pr ≈ k²/2⁶⁵ ≈ 2.7%. At k = 2³² ≈ 4.3×10⁹ the probability is ≥ 1 − e^{−1/2} ≈ 39%. 256-bit IDs at k = 10¹² give ≤ 10²⁴/2²⁵⁷ ≈ 4×10⁻⁵⁴. LBFS's designers note that their 64-bit database keys "have a low but non-negligible probability of collision" and re-verify chunks with SHA-1. — [Muthitacharoen, Chen & Mazières 2001](https://doi.org/10.1145/502034.502052) ([PDF](https://pdos.csail.mit.edu/papers/lbfs:sosp01/lbfs.pdf)).
- **[T6.5] Collision resistance is a computational, not information-theoretic, guarantee, and SHA-1 has failed.** The first full SHA-1 collision took computational effort equivalent to 2^63.1 SHA-1 compressions (~6,500 CPU-years and 100 GPU-years), "more than 100 000 times faster than a brute force search", and was used to forge two PDFs with the same SHA-1. — [Stevens et al. 2017 (SHAttered)](https://shattered.io/static/shattered.pdf). Git, "a content addressable filesystem", names objects by hashing "type, length, a nul byte, and the object's content". After SHAttered it moved to a hardened SHA-1 and is transitioning to SHA-256 because "SHA-1 is still weak". — [Git hash-function-transition doc](https://git-scm.com/docs/hash-function-transition).
- **[T6.6] Merkle trees.** A Merkle tree hash built from a collision-resistant h is collision resistant: a collision at the root implies a collision of h at some node. It supports proofs that an element is in a hashed list with log-size evidence. — [Boneh & Shoup §8.9](https://toc.cryptobook.us/); origin [Merkle 1987](https://doi.org/10.1007/3-540-48184-2_32) (metadata verified). **Maps to (inference):** a snapshot ID equal to the Merkle root over (record ID, record hash) pairs makes "identical repeat answers" checkable in O(1) (compare roots). Snapshot diffs cost O(changed × log n), and any tampered or drifted record changes the root. This is DRC's snapshot pinning made cryptographically verifiable.
- **[T6.7] Content-defined chunking.** LBFS fingerprints every overlapping 48-byte region with Rabin fingerprints and declares a boundary when the low-order 13 bits equal a magic value (probability 2⁻¹³), giving an expected chunk of 2¹³ = 8 KB (plus the window). Because boundaries depend on content, not offset, an edit changes only nearby chunks. Chunks are identified by SHA-1. — [Muthitacharoen et al. 2001](https://pdos.csail.mit.edu/papers/lbfs:sosp01/lbfs.pdf). **Maps to (inference):** chunk sizes are approximately geometric (memoryless boundary process), and an insertion invalidates the chunk containing it and, with high probability, at most the next one. This is the formal version of SKB's observation that content-aware boundaries reduce re-embedding after edits. Fixed-offset chunking shifts all downstream boundaries; per the earlier report it re-embedded 57–68% of a document vs 38–56% for recursive chunking ([SKB report, "Simple segmentation…"](/home/user/agent-data-retrieval/reports/Searchable%20agent%20knowledge%20base%20construction.md)).
- **[T6.8] Dedup effects (empirical).** Near-duplicate removal from LM training data (e.g. a 61-word sentence repeated >60,000 times in C4) gave models that "emit memorized text ten times less frequently" and need fewer steps. — [Lee et al. 2022](https://arxiv.org/abs/2107.06499). Embedding-based semantic dedup removed 50% of a LAION subset "with minimal performance loss". — [Abbas et al. 2023 (SemDeDup)](https://arxiv.org/abs/2303.09540). **Maps to (inference):** for retrieval, a duplicate carries ~0 new bits (K(xx) ≈ K(x) + O(1)) but takes a top-k slot. Duplicates waste the fixed "rate" of the context window, which is the information-theoretic reading of SKB's "duplicates outvote the canonical page". Semantic dedup by embedding similarity has no guarantee of equivalence (paraphrases can differ in one clause), so SKB's "flag, don't delete" is right.

### Inferences
- **A determinism spec for the toolkit (inference).** Canonical IDs = SHA-256 over normalized content plus type and length (Git-style framing), never 64-bit hashes or SHA-1. Snapshot ID = Merkle root. Near-duplicate detection = MinHash with stated (b, r), or SimHash with stated (f, k), plus labeled-pair calibration. Bloom filters only as negative pre-filters. Boundaries content-defined or structural (headings), never fixed-offset, for incremental re-indexing.
- MinHash and SimHash estimate *syntactic* resemblance of shingle sets or weighted features, not semantic equivalence or version identity. Version chains (SKB) must be modeled explicitly. A high-resemblance pair may be two *versions* that must not be collapsed.

### Gaps
- No published analysis bounds the false-merge rate of MinHash-LSH on near-identical policy versions, the case SKB flags as dangerous. Calibration remains empirical.
- The SimHash precision/recall figure (≈0.75 at k = 3) is from 2007 web pages and may not transfer to enterprise documents.

## 7. Entropy-based measures for chunk boundaries and segmentation: TextTiling, MDL segmentation, surprisal and perplexity chunking, and the evidence

### Takeaway
Information-theoretic segmentation is well founded. Text segmentation can be cast as MDL (Utiyama–Isahara), boundaries as surprisal peaks (EM-LLM), or perplexity minima (Meta-Chunking). But the estimators are noisy, context-dependent (entropy rate constancy means context-free surprisal drifts within a document), and expensive. Head-to-head studies find no consistent retrieval gain over simple or structural chunking. Headings are author-supplied boundary codes that cost nothing to estimate, which explains, information-theoretically, why structure-led chunking wins on structured documents.

### Cited Findings
- **[T7.1] TextTiling.** Segments expository text into multi-paragraph subtopic passages using "patterns of lexical co-occurrence and distribution". Adjacent blocks are compared by lexical similarity, and boundaries go at depth-score valleys. Agreement with human judgments was reported on 12 texts. — [Hearst 1997](https://aclanthology.org/J97-1003/). (A similarity method, not strictly entropy-based. It is the baseline the entropy methods replace.)
- **[T7.2] MDL / maximum-probability segmentation.** Utiyama & Isahara find the maximum-probability segmentation, estimating probabilities from the text itself (no training data). The prior on segmentations is a description length: each of m segment lengths is an integer in [1, n] and costs log n bits, so the boundary code costs m log n bits. This penalizes over-segmentation, and the method was at least as accurate as the state of the art at the time. — [Utiyama & Isahara 2001](https://aclanthology.org/P01-1064/). **Maps to (inference):** the m log n term is a principled replacement for the ad hoc "max chunk size" knob. When a document has headings, the author has already paid the boundary code, so a structural splitter gets those bits free.
- **[T7.3] Entropy rate constancy.** If speakers communicate efficiently, entropy per word *given full context* is constant, so local (context-ignoring) entropy estimates should *increase* with sentence position. Genzel & Charniak confirm this with three entropy measures, with both lexical and non-lexical causes. — [Genzel & Charniak 2002](https://aclanthology.org/P02-1026/). **Bounds (inference):** surprisal-based boundary detectors that use a short or no context window will see an upward drift unrelated to topic shifts. Thresholds should be local (e.g. relative to a moving mean, as EM-LLM does) and surprisal should be conditioned on in-document context.
- **[T7.4] Surprisal boundaries (EM-LLM).** A token is a candidate boundary if −log P(x_t | x_1..x_{t−1}; θ) > T with T = μ_{t−τ:t} + γσ_{t−τ:t} (moving-window mean plus γ standard deviations). Boundaries are then refined by maximizing graph modularity or minimizing conductance over attention-key similarity. The method is used for episodic memory over very long contexts and reported superior on LongBench and ∞-Bench. — [Fountas et al. 2025 (ICLR)](https://arxiv.org/abs/2407.09450).
- **[T7.5] Perplexity chunking (Meta-Chunking).** Compute each sentence's perplexity conditioned on preceding sentences, PPL_M(x_i) = average token perplexity given t_<i. Boundaries go at *minima* of the PPL sequence where at least one side differs by more than a threshold θ (with dynamic θ and merging). A margin-sampling variant also exists. — [Zhao et al. 2024 (Meta-Chunking)](https://arxiv.org/abs/2410.12788). Note: Meta-Chunking places boundaries at perplexity *minima*, whereas EM-LLM places them at surprise *peaks*. The two "information-theoretic" chunkers use opposite local criteria, so the information-theoretic label alone does not fix the rule (my observation).
- **[T7.6] LLM-judged segmentation.** LumberChunker prompts an LLM to find where content "begins to shift" and reports +7.37% DCG@20 on GutenQA (narrative books) over the best baseline. — [Duarte et al. 2024](https://arxiv.org/abs/2406.17526). Per the earlier report, an independent reproduction found it best only for in-document needle search over heading-less narratives, and about 1.11 docs/s vs ~1,854 for paragraph splitting ([SKB report](/home/user/agent-data-retrieval/reports/Searchable%20agent%20knowledge%20base%20construction.md)).
- **[T7.7] Evidence against costly semantic segmentation.** Across document retrieval, evidence retrieval and answer generation, "the computational costs associated with semantic chunking are not justified by consistent performance gains". — [Qu, Tu & Bao 2024](https://arxiv.org/abs/2410.13070). The earlier report's larger studies agree (structure-led chunking best on legal and manual corpora; embedding-breakpoint chunker last in Chroma's evaluation) ([SKB report](/home/user/agent-data-retrieval/reports/Searchable%20agent%20knowledge%20base%20construction.md)).

### Inferences
- **Why structure wins (inference).** A segmentation is a code for boundary positions (m log n bits, [T7.2]). Estimated boundaries (TextTiling, surprisal, perplexity, LLM) carry estimation error that costs retrieval quality. Headings, list items and table edges are boundaries the author has already encoded exactly. When they exist, no estimator can do better than reading them, so information-theoretic segmenters should be fallbacks for heading-less text (transcripts, narratives, OCR'd scans). This is SKB's recommendation, now with a reason.
- Surprisal is cheap to compute once per document with a small LM and is deterministic given fixed weights. A defensible default is: structural split first; within oversized heading-less sections, split at sentence boundaries where in-context surprisal exceeds a moving μ + γσ ([T7.4]); MDL-style penalty on the number of segments ([T7.2]). The evidence ([T7.7]) says to expect small gains and to keep the method only if a golden set confirms it.

### Gaps
- No study I found compares surprisal-peak vs perplexity-minimum boundary rules head-to-head on retrieval tasks.
- No theorem connects segmentation description length to downstream retrieval recall. The link is my inference.
